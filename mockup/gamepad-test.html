      วันแข่งต้องเสียบสาย USB เท่านั้น (กติกา R904)
      วันแข่งจอยต้องต่อสาย USB เข้ากับ Driver Station ห้ามใช้ Bluetooth / ไร้สายทุกแบบ รวมถึง DualShock 4 ที่ต่อผ่าน Bluetooth และ Logitech F710 ที่ใช้ตัวรับสัญญาณไร้สาย
      Bluetooth ใช้ได้เฉพาะตอนซ้อมกับ simulator นี้เท่านั้น · ซ้อมด้วยสาย USB อย่างน้อย 1 ครั้งก่อนวันแข่ง
      ขั้นตอนทำอย่างไร
      1. เสียบสายLogitech F310 เป็นจอยมีสาย เสียบ USB เข้าคอมได้เลย ไม่ต้องจับคู่ (วันแข่งก็เสียบสาย USB เข้า Driver Station แบบเดียวกัน)
      2. สวิตช์ด้านหลัง X / Dแนะนำ X (XInput) ปุ่มจะตรงแบบ standard · บน Mac ถ้าตั้ง X แล้วเบราว์เซอร์ไม่เห็นจอย ให้ใช้ D หน้านี้และ simulator เรียงปุ่ม A / B / X ให้ถูกเอง
      3. ปุ่ม MODEให้ไฟข้างปุ่ม MODE ดับ ถ้าไฟติด แกนซ้ายกับ D-pad จะสลับกัน หุ่นจะไม่เดินตามแกน
      4. ให้เบราว์เซอร์เห็นจอยเปิดหน้านี้ใน Chrome หรือ Edge เต็มแท็บ แล้วกดปุ่มใดก็ได้บนจอย 1 ครั้ง
      Joy 1 / Joy 2 ใน Driver Stationกด Start + A = gamepad1 (คนขับ) · Start + B = gamepad2 (คนยิง) ทำทุกครั้งหลังเสียบจอยใหม่
      ปัญหาที่พบบ่อย
      • F710 (ไร้สาย): ต่อผ่านตัวรับสัญญาณไร้สายที่เสียบช่อง USB จึงนับเป็นจอยไร้สาย ซ้อมกับ simulator ได้ แต่วันแข่งห้ามใช้ (R904 ห้ามจอยไร้สาย) วันแข่งให้ใช้จอยที่ต่อสาย USB เข้า Driver Station
      • ปุ่มสลับกัน (กด A แต่ขึ้น X): จอยอยู่โหมด D และเบราว์เซอร์ไม่แปลงปุ่ม ตรวจว่าชื่อจอยมีคำว่า Logitech ระบบจะเรียงให้เอง ถ้ายังผิด เปลี่ยนสวิตช์เป็น X แล้วถอดสายเสียบใหม่
      • D-pad กดไม่ติดในโหมด D: โหมด D ส่ง D-pad มาเป็นแกน (hat) ไม่ใช่ปุ่ม หน้านี้แปลงเป็น D-pad ▲ ▼ ◀ ▶ ให้เองเมื่อ mapping ไม่ใช่ standard ถ้ายังกดไม่ติด เปลี่ยนสวิตช์เป็น X หรือกด "ข้ามปุ่มนี้" (จะถูกบันทึกไว้)
      • LT / RT ค่าไม่ถึง 1: โหมด D ไกเป็นปุ่มกด (0 หรือ 1) โหมด X เป็นค่าต่อเนื่อง ทั้งสองแบบใช้ใน simulator ได้
      • แกน drift: simulator ตัดค่าต่ำกว่า deadzone ของแต่ละจอยอยู่แล้ว ปรับได้ใน Free Control › ตั้งค่าและทดสอบจอย 2 ตัว
      ขั้นตอนทำอย่างไร
      ต่อสาย USB (แบบเดียวกับวันแข่ง)เสียบสาย micro-USB ที่ส่งข้อมูลได้ จอยจะทำงานทันทีโดยไม่ต้องจับคู่ · วันแข่งต้องต่อแบบนี้เข้ากับ Driver Station (R904)
      1. เข้าโหมดจับคู่ Bluetooth
      (ใช้ซ้อมเท่านั้น)      		กดปุ่ม Share ค้างไว้ แล้วกด PS ค้างพร้อมกันประมาณ 3–5 วิ จนไฟแถบด้านหลังกะพริบถี่ ๆ สีขาว
      2. จับคู่บน MacSystem Settings › Bluetooth › หา "Wireless Controller" › กด Connect ไฟจอยจะนิ่ง
      2. จับคู่บน WindowsSettings › Bluetooth & devices › Add device › Bluetooth › เลือก "Wireless Controller"
      3. ให้เบราว์เซอร์เห็นจอยเปิดหน้านี้ใน Chrome หรือ Edge เต็มแท็บ (Safari ใช้ได้ แต่สั่นจอยไม่ได้) แล้วกดปุ่มใดก็ได้บนจอย 1 ครั้ง
      ปัญหาที่พบบ่อย
      • ไม่ขึ้นว่าพบจอย: กดปุ่มบนจอยอีกครั้งตอนที่หน้านี้อยู่ด้านหน้า เบราว์เซอร์ไม่ส่งข้อมูลจอยให้แท็บที่ซ่อนอยู่ ถ้ายังไม่ได้ ลองปิดแล้วเปิดแท็บใหม่
      • ขึ้น mapping ไม่ใช่ "standard": ปุ่มอาจสลับตำแหน่ง ให้ใช้ Chrome หรือ Edge ซึ่งรองรับ DualShock 4 แบบ standard แล้วถอดจอยต่อใหม่
      • จอยจับคู่แล้วแต่ไม่ตอบสนอง: ลบ "Wireless Controller" ออกจาก Bluetooth แล้วจับคู่ใหม่ หรือกดปุ่ม reset รูเล็กด้านหลังจอย (ข้าง L2) ด้วยเข็มประมาณ 5 วิ
      • หลุดบ่อย: ชาร์จแบตให้เต็ม ไฟแถบกะพริบช้าเป็นสัญญาณแบตต่ำ และอยู่ห่างเครื่องไม่เกิน 3–5 เมตร
      • แกน drift (หุ่นขยับเองตอนไม่จับ): simulator ตัดค่าต่ำกว่า 0.10 อยู่แล้ว ถ้าวัดได้เกินนี้ให้ทำความสะอาดแกนหรือเปลี่ยนจอย
      • ปุ่ม PS เปิดเมนูของระบบ: ไม่ได้ใช้ปุ่มนี้ใน simulator ข้ามได้
      • วันแข่ง จอยต้องเสียบสาย USB เข้ากับ Driver Station ห้ามใช้ Bluetooth / ไร้สาย (R904) · ซ้อมด้วยสาย USB อย่างน้อย 1 ครั้งก่อนวันแข่ง และเตรียมสายสำรองไว้ด้วย
